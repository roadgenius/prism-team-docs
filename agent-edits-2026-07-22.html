Agent suggestions are going away.
Agents will just make the edit.

We reviewed how automation suggestions land in the editor. Verdict: the suggestion cards are the problem, not the agents. Here's the before, the after, and how you stay in control.

TL;DR
  • Today: agents file suggestion cards. The page keeps changing under them, so cards go stale, highlight the wrong text, and Approve often can't work.
  • New: agents make the edit in the draft. You review a diff of what changed — which can never go stale.
  • Control: every edit is logged ("changed this → to this"), undoable one-by-one or per run, and nothing publishes without a human.

How you stay in control

🧾
Everything is logged

Each edit keeps a receipt: changed this → to this, which agent, and why. Nothing is silent.

↩️
Everything is undoable

Undo one edit, or a whole run in one sweep. If you already rewrote that bit yourself, your version wins.

🚩
Big changes shout

Rewrites and edits to text you wrote are flagged and shown first. Small fixes stay quiet.

👤
Humans publish

Agents can only touch drafts. Nothing goes live until a person publishes — and unreviewed agent edits are called out there.

What still asks you first: questions. When an agent spots something it can't fix ("these numbers don't add up"), that stays a small note card with a Resolve button — a question has no edit to apply.

Rollout

Step 1 · repair
Fix the current cards — the stuck Approve states, unclickable buttons, wrong highlights, and the "Undo that doesn't undo". Ships first, works either way.
Step 2 · switch
Agents apply + you review the diff — the edit log, undo, flags, and the Show-changes view. The old suggestion machinery gets deleted.
